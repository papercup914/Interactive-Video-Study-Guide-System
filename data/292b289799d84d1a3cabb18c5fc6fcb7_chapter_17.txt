## 1. 우리 주방(작업)에 맞는 셰프(에이전트) 고용하기: 에이전트 유형 3종 세트

영상에서는 에이전트를 고를 때 **"작업의 성격"**을 보라고 합니다. 이걸 식당 주방에 비유하면 이해가 쏙 됩니다.

### ① 시퀀셜 에이전트 (Sequential Agent) — **"레시피대로만 움직이는 주방장"**
> **상황:** "김치찌개 끓이기"처럼 **순서가 정해져 있고, 변수가 거의 없는 단순/반복 작업**일 때.
> - 1단계: 재료 손질 → 2단계: 볶기 → 3단계: 끓이기 → 4단계: 간 보기 → 끝.
> - **"단순하고 예측 가능한 흐름(Simple predictable flows)에는 Sequential이 딱이야."**
> - **비유:** 알바생에게 "이 레시피 종이 보고 1번부터 5번까지 순서대로만 해"라고 시키는 것. 생각할 필요 없이 시키는 대로만 하면 됩니다.

### ② 리액티브 에이전트 (Reactive Agent) — **"홀에서 손님 응대하는 베테랑 매니저"**
> **상황:** 손님이 갑자기 "이거 너무 매워요!", "물 좀 더 주세요!", "화장실 어디예요?"라고 **예측 불가능하게 튀어나오는 동적(Dynamic) 상황**일 때.
> - 정해진 순서가 없습니다. **그때그때 상황(이벤트)에 반응**해서 즉각 행동해야 합니다.
> - **"동적이고 반응적인 작업에는 Reactive가 더 나아."**
> - **비유:** 머릿속에 매뉴얼을 다 외우고 있다가, 손님 콜 벨 울리면 뛰어가서 해결하는 순발력 좋은 매니저.

### ③ 플래닝 에이전트 (Planning Agent) — **"대형 연회(코스 요리) 총괄 셰프"**
> **상황:** "결혼식 피로연 100인분 코스 요리"처럼 **여러 단계(Multi-step)가 있고, 앞 단계가 끝나야 뒷 단계가 시작되는 의존성(Dependencies)이 복잡한 목표**일 때.
> - 애피타이저 → 수프 → 메인 → 디저트... 재료 준비 타이밍, 조리 순서, 서빙 동선까지 **큰 그림을 그리고 계획(Plan)을 짜서 실행**해야 합니다.
> - **"의존성 있는 다단계 목표에는 Planning Agent를 써라."**
> - **비유:** 오늘 예약 현황 보고, 재료 체크하고, 조리사들한테 "너는 전채, 넌 메인, 넌 디저트 맡아. 7시까지 다 나와야 해"라고 **전체 작전을 짜서 지시하는 총주방장**.

> **💡 개념 돋보기: 에이전트 선택 치트키**
> > - **그냥 순서대로만 하면 돼?** → **Sequential** (레시피형)
> > - **상황 봐가며 즉각 반응해야 돼?** → **Reactive** (순발력형)
> > - **복잡한 계획 세워서 단계별로 조율해야 돼?** → **Planning** (전략가형)

## 2. 실전 프로젝트: '블로그 작성 에이전트' 아키텍처 뜯어보기

이제 이론은 그만, 진짜 만들어 봅시다. 우리가 만들 **'블로그 작성 에이전트'**의 요구사항을 보세요.
> **"주제만 주면 → 구조 잡힌 개요(Outline) 짜고 → 본문 쫙 쓰고 → 매력적인 제목과 훅(Hook)까지 제안해줘."**

이건 그냥 순서대로만 하는 게 아닙니다. 개요가 마음에 안 들면 다시 짜야 하고(재시도), 본문 쓰다가 개요랑 안 맞으면 고쳐야 하고(의존성), 제목은 본문 다 보고 나서 뽑아야 하죠? 딱 **플래닝 에이전트**가 필요하겠네요? 근데 ADK에서는 이걸 어떻게 조립할까요? 레고 블록처럼 **세 가지 핵심 부품**으로 만듭니다.

### ① LLM 에이전트 (LLM Agent) — **"머리 좋은 전문가 직원들"**
> 영상에서는 **'플래너(Planner)'**와 **'라이터(Writer)'**가 바로 이 LLM 에이전트입니다.
> - **동력:** 거대한 언어 모델(LLM, 예: Gemini)이 엔진입니다.
> - **역할:** "너는 기획자야(Planner)", "너는 작가야(Writer)"라고 **역할(Persona)과 지시(Instruction)를 줘서 특화**시킨 직원들입니다.
> - **비유:** **"기획팀장님(Planner)"**과 **"필력 좋은 작가님(Writer)"**을 정규직으로 뽑은 겁니다. 둘 다 똑똑한 LLM 뇌를 가졌지만, 맡은 일이 다릅니다.

### ② Loop 에이전트 (Loop Agent) — **"완벽할 때까지 돌려주는 까다로운 품질관리(QA) 팀장"**
> 영상에서는 이 플래너와 라이터를 **Loop Agent로 감쌌다(Wrapped in loop agents)**고 합니다. 이게 바로 ADK의 **워크플로 에이전트(Workflow Agent)**입니다.
> - **핵심 기능:** **"검증(Validation) 실패하면 자동으로 재시도(Retry)해라."**
> - 플래너가 개요 짰는데 엉망이면? → "다시 짜!" → Loop이 플래너를 다시 돌림.
> - 라이터가 본문 썼는데 개요랑 안 맞으면? → "다시 써!" → Loop이 라이터를 다시 돌림.
> - **비유:** 작가님이 초고 가져오면 **"팀장님이 빨간 펜으로 쫙 고쳐서 '이거 고쳐와' 하고 돌려보내는 과정"**을 **자동으로 무한 반복**해주는 시스템입니다. 사람이 안 지켜봐도 알아서 "합격!" 나올 때까지 돌립니다.

### ③ 커스텀 에이전트 (Custom Agent) — **"우리 가게만의 비밀 병기 만들기"**
> 영상 말미에 **"ADK는 베이스 에이전트를 상속(Subclassing)받아 커스텀 에이전트도 만들 수 있게 해줘"**라고 합니다.
> - 기본 부품(LLM, Loop)으로 안 되는 아주 특수한 로직이 필요하면? **직접 클래스를 만들어서 끼워 넣으라는 뜻.**
> - **비유:** 시판 소스로 안 되는 **우리 집만의 '비법 양념장'을 직접 개발해서 쓰는 것**과 같습니다. 프레임워크가 내 마음대로 확장 가능하게 **열려 있다(Extensible)**는 증거죠.

> **💡 개념 돋보기: ADK 에이전트 3단 조립법**
> > 1. **LLM Agent** → 역할 줘서 **전문가 만들기** (기획자, 작가, 비평가...)
> > 2. **Loop Agent** → 전문가들 **감싸서 품질 보장 루프 만들기** (자동 재시도, 검증)
> > 3. **Custom Agent** → 기본 제공 안 되는 **특수 기능 직접 개발해서 끼우기**
> > 이렇게 레고 블록 쌓듯 조립하면 복잡한 '블로그 작성 에이전트'도 뚝딱!

## 3. 개발 환경 세팅: "요리 시작 전 도마와 칼 갈기" (UV & ADK 설치)

코드 한 줄 짜기 전에, 우리 컴퓨터를 '개발 주방'으로 만들어야 합니다. 영상에서는 두 가지를 강조합니다.

### ① UV 설치 — **"초고속 만능 패키지 매니저 (피펫(Pip) + 버추얼엔브(Venv) + 파이썬 설치까지 다 합친 것)"**
> 요즘 파이썬 개발의 **국룰(표준)**이 된 도구입니다. `pip`보다 빠르고, 가상환경 관리도 알아서 해줍니다.
> - **설치 명령어 (터미널에 복붙):**
>   ```bash
>   # 맥/리눅스
>   curl -LsSf https://astral.sh/uv/install.sh | sh
>   
>   # 윈도우 (PowerShell)
>   powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
>   ```
> - **비유:** 예전엔 **'장보러 가서 재료 사오고(pip), 따로 냉장고 정리하고(venv), 불 피우고(python 설치)'** 따로 했는데, **UV는 이 모든 걸 원클릭으로 해결해 주는 '만능 주방 로봇'** 같습니다. 일단 깔아두면 신세계입니다.

### ② Google ADK 설치 — **"에이전트 개발 전용 프레임워크 (우리 주방의 핵심 설비)"**
> UV로 프로젝트 만들 폴더 들어가서 바로 설치합니다.
> - **명령어:**
>   ```bash
>   uv add google-adk
>   ```
>   *(또는 `uv pip install google-adk`)*
> - **비유:** **'에이전트 만들기 전용 최신식 주방 기구 세트(LLM Agent 틀, Loop Agent 틀, 도구 연결 인터페이스 등)'**를 내 작업실에 들이는 과정입니다. 이걸 있어야 `from google.adk.agents import LlmAgent, LoopAgent` 같은 수입(import)이 가능해집니다.

### ③ `agent.py` 파일 생성 — **"레시피 적을 빈 노트 준비"**
> IDE(VS Code, PyCharm 등)에서 프로젝트 폴더 안에 **`agent.py`** 파일을 만듭니다.
> - 여기서부터 우리가 아까 배운 **플래너, 라이터, 루프 에이전트 코드**를 한 줄 한 줄 적어 나갈 겁니다.
> - **비유:** 드디어 **빈 레시피 노트 첫 장을 펼친 상태**입니다. 이제 우리만의 '블로그 자동화 레시피'를 적기만 하면 됩니다.
