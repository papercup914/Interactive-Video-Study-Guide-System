# 🛠️ 챕터 2. 개발 환경 설정: 나만의 AI 에이전트 주방 준비하기

자, 이론 수업은 여기까지! 이제 여러분의 노트북 위에 **'AI 에이전트라는 요리사'가 일할 수 있는 주방**을 직접 차려볼 시간입니다. 방금 강연자분이 "자, 이제 노트북을 여세요"라고 외치신 그 순간부터, 우리는 단순히 강의를 듣는 청중이 아니라 **직접 에이전트를 배포하고 돌리는 엔지니어**가 됩니다.

혹시 "나는 코딩 잘 모르는데...", "터미널이 무서워요..."라는 생각이 드시나요? **전혀 걱정하지 마세요.** 지금부터 제가 **요리 레시피 보듯, 아주 천천히 친절하게** 하나하나 설명해 드릴 테니까요. 자, 앞치마(키보드) 두르고 시작해 볼까요?

---

## 1️⃣ 1단계: 레시피 키트 받아오기 (`git clone`)

강연자분이 화면에 띄워주신 URL로 접속해서 저장소(Repository)를 **복제(clone)**하라고 하셨죠? 이 과정은 마치 **'요리 학원 수강 신청을 하고, 그날 배울 요리의 레시피 북과 재료 키트를 집으로 배송받는 것'**과 똑같습니다.

> 💡 **개념 돋보기: `git clone`이란?**
> > **인터넷 상의 원격 창고(GitHub)에 있는 프로젝트 폴더 전체를, 내 컴퓨터 로컬로 '똑같이 복사해서 가져오는 것'입니다.** 원본은 그대로 둔 채, 내 방(컴퓨터)에 똑같은 방 하나를 새로 만드는 셈이죠. 이제 내 마음대로 재료를 넣고 빼고, 불을 조절해도 원본 레시피에는 아무 영향이 없습니다.

**실행 명령어 (터미널/명령 프롬프트에 입력):**
```bash
git clone [강연자분이_알려주신_URL_주소]
```
*   **팁:** URL은 마우스로 복사해서 터미널에 `우클릭 > 붙여넣기` 하시면 됩니다.

---

## 2️⃣ 2단계: 오늘 실습할 방으로 들어가기 (`cd`)

저장소를 복제했으면, 이제 그 폴더 안으로 들어가야 합니다. 거대한 창고 건물(저장소 루트) 안에 **'Ship Your First Manage Agent'**라는 오늘 수업 전용 강의실이 따로 마련되어 있거든요.

> 💡 **개념 돋보기: `cd` (Change Directory)란?**
> > **'방 이동 명령어'입니다.** 윈도우 탐색기나 맥 파인더에서 폴더를 더블클릭해서 들어가는 것을, 키보드로 텍스트 명령어로 하는 것이라고 보시면 됩니다. `cd 폴더명`이라고 치면 그 폴더 안으로 쏙 들어갑니다.

**실행 명령어:**
```bash
cd Ship Your First Manage Agent
```
*   **주의:** 폴더 이름에 띄어쓰기가 있으면 따옴표로 감싸주세요! (`cd "Ship Your First Manage Agent"`)

## 3️⃣ 3단계: 나만의 위생적인 주방 만들기 (가상환경 `venv` 생성)

**가장 중요하고, 초보자들이 제일 헷갈려하는 단계입니다.** 파이썬으로 프로그램을 돌리려면 도구(라이브러리)들이 필요한데, 이 도구들을 **'내 컴퓨터 전역(글로벌)'에 마구잡이로 깔아두면 나중에 다른 요리(프로젝트) 할 때 재료가 뒤섞여서 큰일 납니다.**

그래서 **'이 프로젝트 전용의 깨끗한 주방(가상환경)'을 하나 새로 만드는 것**입니다.

> 💡 **개념 돋보기: 파이썬 가상환경 (Virtual Environment) 이란?**
> > **'나만의 격리된 파이썬 놀이터'입니다.** 시스템 전체에 깔린 파이썬과 라이브러리를 건드리지 않고, **이 폴더 안에서만 작동하는 독립된 파이썬 환경**을 만듭니다. 마치 **'공용 주방'이 아니라 '내 방 안에 설치된 개인 전용 미니 주방'**을 하나 들이는 것과 같습니다. 여기서 재료(라이브러리)를 쏟아부어도 밖에 있는 다른 요리에는 전혀 영향을 주지 않죠.

### 🍎 맥(Mac) / 리눅스 사용자:
터미널에 아래 두 줄을 **순서대로** 복사해 넣고 엔터 치세요.

```bash
python3 -m venv venv
source venv/bin/activate
```
*   첫 줄(`python3 -m venv venv`): `venv`라는 이름의 **가상환경 폴더(주방 건물)**를 만듭니다.
*   둘째 줄(`source venv/bin/activate`): **그 주방으로 들어가서 불을 켭니다(활성화).** 성공하면 터미널 앞줄에 `(venv)`라고 초록색(또는 파란색) 글씨로 뜨는데, **"지금 넌 네 전용 주방 안에 있어!"**라는 표시입니다.

### 🪟 윈도우(Windows) 사용자:
명령 프롬프트(cmd) 또는 파워쉘(PowerShell)에서 아래 명령어를 차례대로 실행하세요.

```powershell
python -m venv venv
venv\Scripts\activate
```
*   맥과 원리는 똑같습니다. `venv\Scripts\activate`를 치고 나서 프롬프트 앞에 `(venv)`가 뜨면 성공입니다!

---

## 4️⃣ 4단계: 주방에 재료 채워넣기 (`pip install -r requirements.txt`)

주방(가상환경)은 준비됐는데, 아직 냄비도 칼도 재료도 없습니다. `requirements.txt` 파일은 **'이 요리를 하기 위해 필요한 재료(라이브러리) 쇼핑 리스트'**입니다. 이 리스트를 보고 파이썬 패키지 관리자(`pip`)가 자동으로 인터넷에서 다운로드해 주방에 쫙 깔아줍니다.

> 💡 **개념 돋보기: `requirements.txt` 와 `pip install`**
> > *   **`requirements.txt`**: **'필수 장보기 리스트'** (예: streamlit==1.32.0, anthropic==0.25.0 ...)
> > *   **`pip`**: **'자재 담당 직원'**. 리스트를 보고 알아서 창고(인터넷 PyPI)에서 가져와 내 주방(`venv` 폴더 안)에 정리해 줍니다.
> > *   **`-r`**: **'리스트 파일(requirements.txt)을 읽어서 설치해줘'**라는 옵션 플래그입니다.

**실행 명령어 (공통):**
```bash
pip install -r requirements.txt
```
*   화면에 주르륵 글자가 지나가며 `Successfully installed ...`라고 뜨면 **재료 준비 완료!** 입니다. (시간이 좀 걸릴 수 있으니 커피 한 잔 마시는 여유를 가져보세요 ☕)

---

## 5️⃣ 5단계: 비밀 열쇠 넣기 (`.env` 파일 & API 키)

자, 이제 거의 다 왔습니다. 우리 에이전트(요리사)가 **클로드(Claude)라는 천재 수석 셰프의 뇌를 빌려 쓰려면**, **"내가 정식 고객이야!"라고 증명하는 출입증(API Key)**이 필요합니다.

강연자분이 QR 코드로 나눠주신 **Anthropic API Key(무료 크레딧 포함)**를 복사해 두셨나요? 이걸 프로젝트 폴더 최상위에 **`.env`**라는 **비밀 수첩**을 만들어 적어둬야 합니다.

> 💡 **개념 돋보기: `.env` 파일과 환경 변수 (Environment Variables)**
> > **'비밀번호나 중요한 설정값을 코드에 직접 적지 않고, 별도의 숨김 파일에 보관하는 보안 금고'**입니다.
> > *   왜 숨김 파일(.로 시작)인가? → 깃허브에 코드 올릴 때 실수로 비밀번호가 유출되는 걸 막기 위해, git이 기본적으로 무시하게 설정되어 있습니다.
> > *   프로그램(`app.py`)은 시작할 때 이 `.env` 파일을 슬쩍 열어보고 "아, 내 API 키가 이거구나!" 하고 알아서 읽어갑니다.

**하는 방법:**
1.  현재 폴더(`Ship Your First Manage Agent`)에서 **새 파일 생성** → 파일 이름을 **`.env`** 로 저장 (확장자 없고, 앞에 점 `.` 필수!).
2.  메모장이나 VS Code로 열어서 아래 내용을 붙여넣기:
    ```text
    ANTHROPIC_API_KEY=sk-ant-api03-xxxxxxxxxxxxxxxxxxxxxxxx
    ```
    *(뒤에 `xxxx...` 부분에 QR 코드로 받으신 본인의 실제 키를 붙여넣으세요. 따옴표 필요 없습니다.)*
3.  저장 (Ctrl+S / Cmd+S) 후 닫기.

## 6️⃣ 6단계: 영업 개시! (`streamlit run app.py`)

자, 드디어 **가게 문을 여는 순간**입니다. `streamlit`은 데이터 앱을 웹 브라우저로 바로 띄워주는 아주 편리한 도구인데, 우리 에이전트와 대화할 **'홀 서빙 직원(웹 인터페이스)'**을 한 방에 불러주는 역할입니다.

> 💡 **개념 돋보기: `streamlit run app.py`**
> > **'내 파이썬 코드(app.py)를 읽어서, 로컬호스트(내 컴퓨터)에 예쁜 웹사이트 하나를 즉시 띄워달라'**는 명령입니다.
> > *   실행되면 터미널에 `Local URL: http://localhost:8501` 같은 주소가 뜹니다.
> > *   이 주소를 **크롬/사파리/엣지 브라우저 주소창에 복사+붙여넣기(또는 Ctrl+클릭)** 하면, 짠! **내 에이전트와 채팅하는 화면**이 나타납니다.

**실행 명령어 (공통):**
```bash
streamlit run app.py
```

## 🧠 심화 학습: 방금 우리가 세팅한 '주방'의 설계도 이해하기

강연자분이 세팅 직후 바로 코드(`agent.py`)를 열면서 설명해 주신 **핵심 아키텍처 3총사(에이전트, 환경, 세션)**와 **'관리형 에이전트(Managed Agent)'의 마법**을, 우리 주방 비유로 완벽 정리해 드립니다. 이걸 알면 코드 한 줄 한 줄이 왜 필요한지 보입니다.

### 1. 에이전트 (Agent) = **🧠 헤드 셰프 (두뇌, 기획자)**
*   **역할:** "오늘 무슨 요리(작업) 할까? 어떤 재료(도구) 쓸까? 순서 어떻게 짤까?" **생각하고 결정**합니다.
*   **구성품:** `model` (어떤 LLM 쓸지 - 클로드 소넷? 오퍼스?), `mcp_servers` (외부 레시피북 서버), `skills` (특기 요리 기술들).
*   **코드에서:** `agent = Agent(...)` 이 부분이 바로 헤드 셰프 고용 계약서 쓰는 곳입니다.

### 2. 환경 (Environment) = **🍳 주방 & 도구들 (손, 실행자)**
*   **역할:** 헤드 셰프가 "양파 다져!"라고 명령하면, **실제로 칼을 들고 양파를 다지는 물리적 공간**입니다. 코드 실행, 파일 읽기/쓰기, API 호출, 터미널 명령 등 **실제 행동**이 일어나는 컨테이너(샌드박스)입니다.
*   **중요 포인트:** 강연자분이 강조하신 **'뇌(에이전트 루프)와 손(환경/도구 실행)의 분리(Decoupling)'**가 바로 **"헤드 셰프 사무실(뇌)"과 "실제 주방(손)"을 별도 건물로 떨어뜨려 놓은 것**입니다.
    *   **왜?** ① **보안:** 헤드 셰프가 주방 금고(비밀번호, 키) 열쇠를 직접 안 갖고 있어도 됨. ② **속도:** 주방만 가볍게 띄우면 되니 '첫 토큰까지 시간(TTFT)'이 90%나 단축됨 (P95 기준).

> 💡 **개념 돋보기: 뇌와 손의 분리 (Decoupling Agent Loop & Tool Execution) - 왜 혁신인가?**
> > **기존 방식 (Coupled):** 셰프가 주방 안에서 생각도 하고 칼질도 함. 손님(세션) 하나 올 때마다 **주방 통째로(컨테이너 하나)를 새로 지어야 함** → 시간 오래 걸림, 보안 위험.
> > **Claude Managed Agent 방식 (Decoupled):**
> > *   **뇌(에이전트 루프)**는 **서버 사이드(클라우드 본사)**에서 24시간 켜져 있음. 내 노트북 꺼도, 브라우저 새로고침 해도 **생각의 흐름(상태)이 그대로 유지됨 (Durability/Reliability 보장)**.
> > *   **손(환경/컨테이너)**은 필요할 때만 가볍게 띄워서 행동만 하고 내려감.
> > *   **결과:** 프로토타입 → 프로덕션 갈 때 겪는 '호스팅, 스케일링, 상태 관리' 골치 아픈 걸 **전부 클라우드 본사가 떠안아 줌**. 우리는 그냥 요리(로직)만 짜면 됨!

### 3. 세션 (Session) = **📋 주문서 & 근무 교대 일지 (연결고리)**
*   **역할:** **"이 손님(유저)을 위해, 이 헤드 셰프(에이전트)가, 이 주방(환경)에서, 지금부터 일 시작해!"** 하고 **둘을 공식적으로 묶어주는 단위**입니다.
*   **기능:** 세션 하나가 생기면 → 지정된 환경에 에이전트 인스턴스 하나가 스폰(생성)됨 → 이후 주고받는 대화 이벤트(스트리밍)를 이 세션이 관리하며 유저에게 전달.

## 📝 요약: 지금 여러분 터미널에서 일어난 일

| 명령어 | 주방 비유 | 기술적 의미 |
| :--- | :--- | :--- |
| `git clone` | 레시피 키트 배송받기 | 원격 저장소 복제 |
| `cd ...` | 오늘 수업 강의실 입장 | 작업 디렉토리 이동 |
| `python -m venv venv` | 내 방에 미니 주방 짓기 | 가상환경 생성 (격리) |
| `source venv/bin/activate` | 미니 주방 불 켜고 들어가기 | 가상환경 활성화 |
| `pip install -r requirements.txt` | 장봐서 주방 채우기 | 의존성 패키지 설치 |
| `.env` 에 API Key 적기 | 비밀 출입증 금고에 넣기 | 환경 변수 설정 (보안) |
| `streamlit run app.py` | 가게 문 열고 손님 맞이 | 웹 서버 실행 & UI 렌더링 |

## 💪 튜터의 한 마디

> **"개발 환경 설정은 '귀찮은 준비 운동'이 아닙니다. 내 코드가 숨 쉬고, 내 에이전트가 안전하게 뛰놀 '집'을 짓는 신성한 의식입니다."**

지금 `streamlit run app.py`로 화면이 떴다면, **여러분은 이미 '프로덕션 레디 에이전트'를 로컬에서 돌릴 수 있는 인프라를 갖춘 엔지니어**입니다. 혹시 에러가 나서 안 뜨나요? 에러 메시지 그대로 복사해서 저에게(또는 검색창에) 물어보세요. 에러는 **'이 재료가 없다', '저 문법이 틀렸다'고 친절히 알려주는 레시피 수정 노트**일 뿐입니다.

자, 이제 `agent.py` 파일을 열고, 오른쪽 `agent_complete.py`에서 **첫 번째 퍼즐 조각(Agent 정의 부분)**을 가져와 붙여넣기 해 볼까요? **다음 챕터에서 본격적으로 '헤드 셰프 고용 계약서'를 작성하러 갑시다!** 🚀
