# Chapter 4. requirements.txt 설치 및 .env 파일에 Anthropic API 키 설정: 에이전트의 '식재료' 준비하고 '출입증' 발급받기

자, 이제 본격적으로 우리 컴퓨터 위에 '클로드 매니지드 에이전트'라는 멋진 로봇을 조립할 준비를 해볼까요? 강사님이 깃허브(GitHub) 저장소를 복제(`git clone`)해오라고 하셨죠? 마치 **'조립 설명서'와 '부품 상자'가 든 택배 박스를 현관 앞에 갖다 놓은 상태**라고 보시면 됩니다.

이제 박스를 열어서(`cd` 명령어), 내 작업실(가상 환경)을 만들고, 부품 목록(`requirements.txt`)을 보고 재료를 사다 놓고(`pip install`), 마지막으로 이 로봇이 클로드( Claude)라는 거대한 두뇌와 통신할 수 있게 해줄 **'출입증(API Key)'**을 발급받아 지갑(.env 파일)에 넣어두는 과정까지 차근차근 해보겠습니다.

---

## 1. 작업실로 들어가기: `cd` 명령어와 폴더 이동

터미널(명령 프롬프트)을 켜면 보통 '홈' 디렉토리나 사용자 폴더에 있게 됩니다. 아까 `git clone`으로 받은 저장소 폴더(예: `Ship Your First Manage Agent`) 안으로 들어가야 합니다.

```bash
cd "Ship Your First Manage Agent"
```

> **💡 개념 돋보기: `cd` (Change Directory)**
> > `cd`는 **'방 옮기기(Change Directory)'**의 약자입니다. 윈도우 탐색기나 맥 파인더에서 폴더를 더블클릭해서 들어가는 것과 **완전히 똑같습니다**. 단지 마우스 대신 키보드로 글자를 쳐서 들어갈 뿐이죠. 폴더 이름에 띄어쓰기가 있으면(예: `Ship Your First Manage Agent`), 꼭 큰따옴표(`" "`)나 작은따옴표(`' '`)로 감싸주세요. 안 그러면 "Ship" 폴더로 가려다 에러가 납니다.

## 2. 나만의 깨끗한 작업실 만들기: 가상 환경(Virtual Environment) 생성

강사님이 맥(Mac)에서는 `python -m venv venv` 하고 `source venv/bin/activate` 하라고 했고, 윈도우도 별도 명령어가 있다고 했죠? 이 과정이 **가장 중요하고, 초보자가 제일 헷갈려하는 부분**입니다.

### 왜 굳이 '가상 환경'을 만드나요? (비유: 나만의 전용 주방)

여러분의 컴퓨터에는 이미 '시스템 파이썬'이라는 **공용 주방**이 있습니다. 여기서 요리(코딩)하면 누구나 쓰는 칼, 도마, 재료(라이브러리)가 뒤섞여서 엉망이 되기 쉽습니다. 프로젝트 A에는 '장고 3.0'이 필요한데, 프로젝트 B에는 '장고 4.0'이 필요하면? 공용 주방에서는 둘 다 설치할 수 없어서 싸움이 납니다.

그래서 **나만의 전용 주방(가상 환경)**을 하나 만듭니다. 여기선 내 맘대로 재료를 깔아도, 시스템 주방이나 다른 프로젝트 주방에 **절대 영향을 주지 않습니다.**

### 맥/리눅스 사용자라면:

```bash
# 1. 'venv'라는 이름의 전용 주방(폴더) 하나 만들어줘
python -m venv venv

# 2. 이제 이 주방으로 들어갈게 (활성화)
source venv/bin/activate
```

### 윈도우 사용자라면 (명령 프롬프트 cmd 기준):

```cmd
# 1. 주방 만들기
python -m venv venv

# 2. 주방 들어가기 (활성화 스크립트 실행)
venv\Scripts\activate.bat
```
*(파워쉘 PowerShell 쓰신다면 `venv\Scripts\Activate.ps1` 인데, 보안 정책상 에러 나면 `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` 한번 치고 다시 해보세요.)*

> **💡 개념 돋보기: `python -m venv venv` 해석하기**
> > *   `python`: 파이썬 실행해줘.
> > *   `-m venv`: `venv`라는 **모듈(기능)**을 실행해줘. (가상 환경 만들어주는 공식 도구)
> > *   `venv` (맨 뒤): **만들어질 폴더 이름**을 `venv`로 할게. (이름은 아무거나 해도 됨. `myenv`, `kitchen` 다 됨)
> >
> > **성공하면 터미널 앞부분에 `(venv)` 라고 뜨습니다.** 이게 "지금 너 전용 주방 안에 있어!"라는 표시등입니다. 이 표시가 떠 있어야 `pip install` 했을 때 이곳에만 깔립니다.

## 3. 장보기: `requirements.txt` 설치하기 (`pip install -r requirements.txt`)

작업실(가상 환경) 들어왔으니 이제 재료를 사다 놓아야죠. 강사님이 `pip install -r requirements.txt` 치라고 했습니다.

```bash
pip install -r requirements.txt
```

### `requirements.txt`가 뭐예요? (비유: **'장보기 리스트/레시피 재료표'**)

이 파일 안에는 이렇게 적혀 있을 겁니다.
```text
anthropic==0.25.0
streamlit==1.32.0
python-dotenv==1.0.1
...
```
*   **이름**: `anthropic`, `streamlit` 등 (패키지 이름)
*   **버전**: `==0.25.0` (딱 이 버전으로 사와! 업데이트돼도 이 버전 고정!)

### `pip install -r requirements.txt` 해석하기

> **💡 개념 돋보기: `pip install -r requirements.txt` 분해**
> > *   `pip`: **파이썬 패키지 설치 도우미(Pip Installs Packages)**. 인터넷 상점(PyPI)에서 물건 사다 주는 배달부.
> > *   `install`: 사다 놔(설치해).
> > *   `-r`: **`-requirement`(요구사항)의 약자**. "낱개로 주문 안 할게, **리스트 파일 하나 주니까 이거 보고 싹 다 사와**"라는 뜻.
> > *   `requirements.txt`: 그 리스트 파일 이름.
>
> > **즉, "심부름꾼아, 이 장보기 리스트(`requirements.txt`) 보고 적힌 거 **버전까지 딱 맞춰서** 내 전용 주방(`venv`)에 싹 다 갖다 놔!"** 라는 명령입니다.

터미널에 줄줄글글 다운로드 되고 `Successfully installed ...` 뜨면 장보기 끝! 내 작업실에 `anthropic`, `streamlit` 같은 라이브러리들이 가지런히 진열된 겁니다.

## 4. 신분증(출입증) 발급 및 보관: `.env` 파일에 Anthropic API Key 넣기

자, 재료는 다 갖췄습니다. 이제 우리 에이전트가 **'클로드(Anthropic)의 거대 두뇌'**를 빌려 쓰려면 인증이 필요합니다. 강사님이 QR 코드로 무료 크레딧 받으라고 했죠? 거기서 받은 **긴 문자열(API Key)**이 바로 **'출입증'**입니다.

### 4-1. `.env.example` → `.env` 복사하기 (템플릿 복사)

보통 저장소에는 `.env.example`이라는 **빈 템플릿**만 들어있습니다. 진짜 비밀번호가 들어갈 `.env` 파일은 보안상 깃허브에 올리지 않기 때문입니다(`.gitignore`에 등록돼 있음).

```bash
# 맥/리눅스
cp .env.example .env

# 윈도우 (cmd)
copy .env.example .env
# 윈도우 (파워쉘)
Copy-Item .env.example .env
```

> **💡 개념 돋보기: `.env` 파일과 `python-dotenv` 라이브러리**
> > *   **`.env` (Dot Env)**: **환경 변수(Environment Variables)**를 저장하는 **숨김 파일**입니다. 파일 이름 앞에 점(`.`)이 붙어 있어서 폴더에서 안 보입니다(`ls -a` 해야 보임).
> > *   **왜 쓰나요?** 코드(`app.py`)에 `api_key = "sk-ant-..."` 이렇게 하드코딩(박제)하면 **깃허브에 올릴 때 비밀번호가 다 털립니다.** 큰일 나요.
> > *   **해결책:** 코드에서는 `os.getenv("ANTHROPIC_API_KEY")` 라고만 쓰고, **진짜 값은 `.env` 파일에만** 둡니다. `.env`는 `.gitignore`로 업로드 차단하면 안전하죠.
> > *   **`python-dotenv` 라이브러리**: 파이썬이 `.env` 파일을 읽어서 환경 변수처럼 쓸 수 있게 해주는 **통역사** 역할입니다. 아까 `requirements.txt`에 있던 게 이거예요!

### 4-2. `.env` 파일 열어서 키 붙여넣기

이제 `.env` 파일을 열어야 합니다. 터미널에서 `code .env` (VS Code 설치돼 있다면) 치거나, 탐색기/파인더에서 폴더 열어서 `.env` 파일을 더블클릭/우클릭-연결프로그램-VS Code로 여세요.

열면 아마 이렇게 텅 비어 있거나 주석만 있을 겁니다.
```env
# .env 파일 예시
ANTHROPIC_API_KEY=your_api_key_here
```

여기에 아까 발급받은 **API Key(sk-ant-api03-...로 시작하는 긴 문자열)**를 `=` 뒤에 **띄어쓰기 없이** 붙여넣기 하세요.

```env
# 수정 후
ANTHROPIC_API_KEY=sk-ant-api03-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

> **⚠️ 아주 중요한 주의사항 (실수 방지 체크리스트)**
> 1.  **큰따옴표(`"`)나 작은따옴표(`'`)로 감싸지 마세요.** 그냥 `=sk-ant...` 가 맞습니다. (파이썬 `dotenv` 라이브러리가 따옴표까지 문자열로 인식할 수 있어요.)
> 2.  **앞뒤 공백 금지.** `= sk-ant...` (등호 뒤에 띄어쓰기) 안 됩니다. `=sk-ant...` 딱 붙여야 해요.
> 3.  **줄바꿈/엔터 조심.** 키 중간에 엔터 쳐서 두 줄 되지 않게 한 줄로 쭉 이어져야 합니다.
> 4.  **저장(Ctrl+S / Cmd+S) 필수!** 안 누르고 터미널 가면 안 읽힙니다.

## 5. 전체 흐름 복습: 한눈에 보는 설정 순서도

터미널에서 순서대로 쭉 치면 이렇게 됩니다. (맥/리눅스 기준)

```bash
# 1. 택배 박스(저장소) 안으로 들어감
cd "Ship Your First Manage Agent"

# 2. 나만의 전용 주방(가상 환경) 짓기
python -m venv venv

# 3. 전용 주방으로 들어감 (프롬프트 앞에 (venv) 뜨는지 확인!)
source venv/bin/activate

# 4. 장보기 리스트 보고 재료 싹 다 사오기
pip install -r requirements.txt

# 5. 비밀 출입증 템플릿 복사해서 진짜 출입증 만들기
cp .env.example .env

# 6. .env 파일 열어서 API Key 붙여넣고 저장 (편집기에서 수동 작업)

# 7. 이제 앱 실행! (다음 챕터에서 할 일)
# streamlit run app.py
```

## 6. 자주 묻는 질문 (FAQ) & 트러블슈팅

### Q1. `python` 명령이 안 먹어요 / `python3` 라고 쳐야 돼요.
**A.** 맥/리눅스에서는 `python3 -m venv venv`, `pip3 install ...` 처럼 뒤에 `3`을 붙여보세요. 윈도우에서는 설치할 때 'Add to PATH' 체크 안 해서 그런 경우가 많으니 파이썬 재설치하며 PATH 추가하세요.

### Q2. `source venv/bin/activate` 했는데 `(venv)` 표시가 안 떠요.
**A.** 현재 폴더가 맞는지 `pwd`(맥/리눅스)나 `cd`(윈도우)로 확인하세요. `venv` 폴더가 있는 위치에서 명령 쳐야 합니다. `ls` 해봐서 `venv` 폴더가 보이면 맞습니다.

### Q3. `pip install` 중 빨간 에러 글자가 떠요 (`ERROR: Could not build wheels...` 등).
**A.** 보통 C++ 빌드 도구(Visual Studio Build Tools 윈도우, Xcode Command Line Tools 맥)가 없거나, 파이썬 버전이 너무 높아서(예: 3.13) 라이브러리가 아직 지원을 안 해서 그렇습니다.
*   **임시 해결:** `pip install --only-binary :all: -r requirements.txt` (바이버리만 받으라고 강제)
*   **근본 해결:** 파이썬 3.10 또는 3.11 버전으로 가상 환경 만드세요(`python3.11 -m venv venv`).

### Q4. API Key 넣었는데 `streamlit run app.py` 하니 `AuthenticationError` 떠요.
**A.**
1.  `.env` 파일 저장 안 한 거 아닌지 확인(Ctrl+S).
2.  키 앞뒤 공백/따옴표 없는지 확인.
3.  터미널 껐다 켜고 `source venv/bin/activate` 다시 해서 `streamlit run app.py` 해보세요(환경 변수 재로딩).
4.  Anthropic 콘솔 가서 키가 'Active' 상태인지, 크레딧 남은 건지 확인.

### Q5. `.env` 파일 git에 안 올라가게 확실히 막으려면?
**A.** 프로젝트 루트에 `.gitignore` 파일이 있는데, 안에 `.env` 한 줄 적혀 있는지 확인하세요. 없다면 직접 추가하세요. **이건 필수입니다.**
