# 프론트엔드 코드 분석

프론트엔드는 Next.js(React)와 Tailwind CSS를 활용해 구축되었습니다.

## 1. 폴더 및 라우팅 구조 (Next.js App Router)
* `src/app/page.tsx`: 랜딩 페이지 및 URL 입력 폼 (진입점).
* `src/app/guide/[jobId]/page.tsx`: 핵심 화면입니다. 생성된 스터디 가이드를 렌더링하고, 사용자의 드래그(Selection) 이벤트를 감지하여 툴바(Toolbar)를 띄우는 책임을 집니다.
* `src/components/markdown/RealStudyElements.tsx`: 마크다운 내에 삽입된 `<highlight>`, `<scribble>` 등의 커스텀 태그를 실제 시각적인 HTML/CSS 요소로 변환해 주는 React 컴포넌트들의 집합소입니다.

## 2. 실감나는 마킹 시스템 (RealStudyElements.tsx)
단순한 밑줄이 아니라 "진짜 펜으로 그은 듯한" 아날로그 느낌을 주기 위해 여러 CSS 트릭이 사용되었습니다.

### 형광펜 (`<Highlight>`)
형광펜은 글자 뒤에 칠해져야 하므로 렌더링 레이어(z-index) 관리가 필수적입니다.
```tsx
<span className="relative inline-block px-1 mx-1 font-bold z-0">
  <span className="absolute inset-0 bg-[#eaff00]/70 transform -skew-x-12 -rotate-1 rounded-sm -z-10"></span>
  {children}
</span>
```
`absolute`와 `-z-10`을 사용하여 텍스트 바로 뒤에 색상을 깔고, `skew`와 `rotate`를 미세하게 주어 손으로 삐뚤게 칠한 느낌을 줍니다.

### 동그라미 (`<Scribble>`)
SVG의 `<path>`를 직접 그려 펜의 궤적을 만들었습니다.
개발 과정에서 SVG가 주변 요소를 침범하거나 화면 밖으로 잘리는 현상이 있어 `overflow-visible`과 `vectorEffect="non-scaling-stroke"`를 적용했습니다.
동그라미가 좌측 하단에서 엇갈리며 닫히도록 `M 15,85 C 30,105 ...`와 같이 베지어 곡선(Bezier Curve) 좌표를 수학적으로 조정하여 상하 반전된 역동적인 펜 선을 완성했습니다.

### 포스트잇 (`<MarginNote>`)
우측 빈 공간에 떠 있는 포스트잇을 구현하기 위해 `group-hover`를 활용했습니다.
눈에 보이지 않는 투명한 상태일 때 마우스 포인터를 가로채지 않도록 `pointer-events-none` 속성을 부여하여 낚시 현상을 방지한 것이 기술적 핵심입니다.

## 3. 커스텀 태그 파싱 (`rehype-raw`)
사용자가 드래그 후 형광펜 버튼을 누르면, 프론트엔드 로직은 원본 텍스트를 `<highlight>선택된 텍스트</highlight>` 형태의 HTML 문자열로 치환합니다.
이후 `react-markdown` 라이브러리가 `rehype-raw` 플러그인을 거쳐 이 커스텀 태그를 인식하고, 우리가 정의한 `Highlight` React 컴포넌트로 1:1 매핑하여 화면에 그려냅니다.
